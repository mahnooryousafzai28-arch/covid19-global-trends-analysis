# COVID-19 Global Trends Analysis

Exploratory data analysis of global COVID-19 case data, examining how the 
pandemic spread over time, which countries and regions were most affected, 
and how confirmed cases, deaths, and recoveries relate to one another.

## Dataset
COVID-19 Clean Complete dataset — daily confirmed cases, deaths, and 
recoveries by country/region (Jan 22 – Jul 27, 2020).

## Key Findings
- Global confirmed cases grew exponentially starting around March 2020.
- The US, Brazil, and India had the highest case counts, but Yemen and 
  several Western European countries had the highest fatality rates — 
  showing case volume alone doesn't determine severity.
- The Americas and Europe were the most affected regions overall.
- Confirmed cases were strongly correlated with deaths (0.91) and recoveries 
  (0.90), while the death-recovery relationship varied more by country.

## Tools Used
Python, pandas, matplotlib, seaborn, Jupyter Notebook
